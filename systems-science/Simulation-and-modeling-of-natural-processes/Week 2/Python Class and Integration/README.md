# Week 2 - Numerical Integration

**Overview**
- Demonstrates numerical integration of a smooth function using Riemann sums and the trapezoidal rule.

**Files**
- `Project_ClassIntegration.py`: Integration strategies and a small demo.

**Algorithm**
- Discretize the interval into `N` points.
- Evaluate `f(x)` at sample points.
- Multiply by `dx` and sum (Riemann) or use the trapezoidal rule to average endpoints.

**Run**
```bash
python "Project_ClassIntegration.py"
```

**Dependencies**
- `numpy`
